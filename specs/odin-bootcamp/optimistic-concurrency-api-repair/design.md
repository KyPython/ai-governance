## Correctness Properties

### Property 1: conditional mutation against the version precondition (INV-1)
WHERE a client update is applied against the in-memory resource store, THE update function SHALL (a) apply the update and advance state when the client's expected version matches the current stored version; (b) return the specified client-validation result for a malformed request without mutating state; (c) return the specified conflict result and PRESERVE the newer stored state when the client's expected version does not match the stored version (a stale write); and (d) handle repeated and unchanged-resource requests deterministically.
